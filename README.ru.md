# os-xray-hev — форк MrTheory/os-xray

Это независимый форк [MrTheory/os-xray](https://github.com/MrTheory/os-xray), исходный автор — Pavel. Оригинальная лицензия BSD-2-Clause и авторские уведомления сохранены. Форк поддерживается [xndevmain](https://github.com/xndevmain); это не официальный плагин OPNsense и не релиз оригинального автора.

**Версия 4.0.0-beta.1.** Проверенное окружение: OPNsense 26.7 / FreeBSD 15.1 amd64, PHP 8.5, Xray 26.10.31, HevSocks5Tunnel 2.19.3, Unbound 1.25.1. Совместимость с другими версиями не заявляется. [Результаты аудита](docs/PUBLIC-AUDIT.txt) и [ограничения безопасности](docs/SECURITY.txt).

## Что изменено

Один туннель Xray + HevSocks5Tunnel вместо tun2socks; каталог серверов и подписок; VLESS, VMess, Trojan, Shadowsocks; выбор серверов и сохранение отключённого состояния при обновлении; автоматическое переключение; geosite/geoip и доменные списки через Unbound/PF; вкладки General, Endpoints, Subscriptions, Routing, Diagnostics, Log; локализация EN/RU штатным gettext.

В туннель попадает трафик, выбранный правилами OPNsense. Внутри Xray он направляется через выбранные прокси. Один экземпляр поддерживает до 32 различных активных серверов; общий каталог — до 1024 записей.

## Установка

Установите проверенные сборки Xray-core и HevSocks5Tunnel в `/usr/local/bin/xray-core` и `/usr/local/bin/hev-socks5-tunnel`. Нужны Python 3 с sqlite3 и dnspython, PHP 8.3+ с curl и Phalcon, Unbound OPNsense с Python-модулем. Установщик не скачивает и не заменяет исполняемые зависимости.

Распакуйте весь архив релиза, проверьте SHA-256, затем от root:

```sh
sh install.sh --check
sh install.sh
```

До замены проверяются модели и шаблоны, создаётся резервная копия. Работающий туннель не останавливается установщиком; после установки проверьте настройки и нажмите Apply. Поддержана миграция текущей схемы одного туннеля с outbound JSON. Старые wizard-схемы и несколько экземпляров отклоняются до замены файлов: для них требуется ручная миграция.

1. VPN → Xray → Subscriptions → Add subscription: имя и HTTPS URL. После сохранения сразу загружается список серверов. Разовый импорт ссылок/файла доступен в Endpoints.
2. В Endpoints включите нужные серверы и нажмите Apply. Новые серверы подписки изначально выключены.
3. В General включите Xray, создайте интерфейс и шлюз. Для /30 кнопка шлюза выбирает второй пригодный адрес.
4. В Routing загрузите geosite/geoip, выберите категории/домены, нажмите Apply Firewall Lists.
5. Проверьте правило LAN: назначение XRAY_HOSTS, шлюз туннеля. Правило должно стоять перед общим разрешающим правилом LAN, сохраняя приоритет предыдущих ограничений. Кнопка правила сохраняет его; применение выполняется в штатном Firewall UI.
6. DNS клиентов должен идти через Unbound OPNsense. Проверяйте не только прокси, но и реальный путь трафика клиента через правило и TUN.

Обновление подписки сохраняет индивидуальный Enabled, переименования и порядок не сбрасывают выбор. Новые адреса/учётные данные/транспорты считаются новыми серверами. Удалённые подписные записи запоминаются и не восстанавливаются автоматически. Пропавший сервер исключается, при возвращении той же идентичности сохраняется прежний выбор. Старые ручные импорты не привязываются к источнику автоматически: URL ранее не сохранялся.

Планировщик проверяет интервалы раз в пять минут, минимальный интервал — 15 минут. Автоприменение разрешено только при совпадении работающего и ранее сохранённого конфигов; при неприменённых изменениях или остановленной службе нужен Apply. Для отключения последнего активного сервера сначала отключите Xray. Существующие соединения при переключении могут требовать переподключения.

## Удаление

```sh
sh install.sh uninstall
```

Удаление останавливает процессы плагина, убирает Unbound callback и пересоздаёт cron. Настройки config.xml, зависимости, логи и geodata сохраняются. Правила, шлюзы и назначения интерфейсов проверьте и удалите отдельно. Резервные копии находятся в указанном установщиком каталоге `/root/os-xray-backup.*`. Восстанавливайте совместимые код и конфигурацию вместе; не затирайте старой копией новые посторонние настройки.

## Проверки и сборка

```sh
python3 tools/check.py
python3 tests/failover.py /path/to/xray
python3 tools/build_release.py
```

Нужны PHP, Python и Node.js. Тест FreeBSD `tests/freebsd_unbound.py` запускается от root и использует отдельный экземпляр Unbound и тестовую PF-таблицу. Сборка архива идёт по явному списку разрешённых файлов и исключает локальные данные, резервные копии роутера и внутренние отчёты развёртывания.
